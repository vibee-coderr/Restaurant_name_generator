# Restaurant Name Generator 🍽️

A simple AI-powered Restaurant Name Generator built using Python, Streamlit, and LangChain.

This application helps users generate creative restaurant names based on their selected cuisine. It also suggests menu items that match the restaurant name and cuisine.

## Features

- Select a cuisine from the sidebar.
- Generate creative and unique restaurant names.
- Get suggested menu items based on the selected cuisine.
- Simple and user-friendly interface.

## Tech Stack

- Python
- Streamlit
- LangChain
- Large Language Models (LLMs)

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/vibee-coderr/Restaurant_name_generator.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Restaurant_name_generator
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt  (if u created it ... im haven't)
   ```

4. Run the application:

   ```bash
   streamlit run main.py
   ```
